# Proyek Animasi Grafika dan Multimedia - Jejak Makna dalam Sehelai Batik

Repository ini berisi source code, aset visual, dan dokumentasi untuk proyek akhir mata kuliah Grafika dan Multimedia. Proyek ini berupa animasi interaktif berbasis Processing yang menampilkan filosofi batik melalui narasi visual, audio, subtitle, dan transisi scene yang teratur.

## Deskripsi Singkat

Animasi ini menghadirkan makna dari motif batik seperti Kawung, Megamendung, dan Parang melalui visual yang bergerak dan terdengar. Karya ini menggabungkan elemen grafis generatif, transisi animasi, narasi audio, dan subtitle sehingga penonton bisa memahami pesan budaya yang ingin disampaikan.

## Fitur Utama

- Animasi scene bertahap dengan transisi yang halus
- Narasi audio dan subtitle yang mengikuti alur cerita
- Efek fade in/out untuk memperjelas pergantian scene
- Interaksi sederhana melalui klik mouse untuk melompat ke scene berikutnya
- Penggunaan elemen visual seperti kunang-kunang, awan, dan motif batik sebagai penunjang estetika

## Struktur Proyek

- AnimasiBatik/: folder utama proyek Processing
  - AnimasiBatik.pde: file utama program animasi
  - data/: folder aset gambar dan audio
- Docs/: dokumen pendukung proyek

## Persyaratan

- Processing IDE (rekomendasi: Processing 4.x)
- Library Processing Sound

## Cara Menjalankan Program

1. Buka aplikasi Processing.
2. Buka file [AnimasiBatik/AnimasiBatik.pde](AnimasiBatik/AnimasiBatik.pde).
3. Pastikan library Sound terinstal:
   - Pilih Sketch > Import Library > Add Library
   - Cari "Sound" lalu install
4. Tekan tombol Run atau gunakan shortcut Ctrl+R.
5. Jika ingin melihat scene berikutnya lebih cepat, klik mouse di area window animasi.

## Catatan Tambahan

Program ini memerlukan file audio dan gambar yang berada di folder data di dalam [AnimasiBatik](AnimasiBatik). Pastikan semua file tersebut tetap ada sebelum dijalankan.
